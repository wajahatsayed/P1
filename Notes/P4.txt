PRACTICAL 4 - REPLICATION, BACKUP AND RESTORE
=============================================

SYLLABUS REQUIREMENTS
---------------------
a) Create a replica of an existing database.
b) Create a backup of an existing database.
c) Restore a database from backup.

IMPORTANT
---------
This practical is environment-dependent. The syllabus states the tasks, but the
retrieved practical PDFs did not provide a complete step-by-step command sheet.
The commands below are the standard command-line patterns to know for the
college VMware/lab environment.

BACKUP WITH MONGODUMP
---------------------
Run from normal CMD, outside the mongo shell:

mongodump --db BDNS --out C:\MongoBackup

Backup one collection:
mongodump --db BDNS --collection student --out C:\MongoBackup

RESTORE WITH MONGORESTORE
-------------------------
mongorestore --db BDNS C:\MongoBackup\BDNS

If restoring to a different database name:
mongorestore --db BDNS_Restore C:\MongoBackup\BDNS

VERIFY AFTER RESTORE
--------------------
mongo
show dbs
use BDNS_Restore
show collections
db.student.find()

REPLICATION - CONCEPTUAL COMMAND PATTERN
----------------------------------------
Replication normally requires a replica-set configuration and multiple mongod
instances/ports. Do NOT invent a replica setup during the exam if the college VM
already provides one.

Typical server startup pattern:

mongod --replSet rs0 --port 27017 --dbpath C:\data\db1
mongod --replSet rs0 --port 27018 --dbpath C:\data\db2
mongod --replSet rs0 --port 27019 --dbpath C:\data\db3

Then connect to one server and initialize:

mongo --port 27017

rs.initiate()

Check:
rs.status()

Add members (only if the lab setup requires it):
rs.add("localhost:27018")
rs.add("localhost:27019")

Check:
rs.status()

IMPORTANT EXAM NOTE
-------------------
Exact dbpath, ports, service names and replica-set instructions depend on the
college VMware configuration. Use the values provided by the teacher/VM rather
than blindly using the example paths above.
