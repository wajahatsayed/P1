MONGODB / BDNS PRACTICAL COMMAND SHEETS
========================================

Purpose
-------
These files are exam-oriented command sheets prepared from the available college
BDNS syllabus and practical PDFs, with clearly marked supplemental commands where
the retrieved practical PDF did not contain a complete command set.

IMPORTANT NUMBERING NOTE
------------------------
The syllabus lists:
5. Java + MongoDB
6. PHP + MongoDB
7. Python + MongoDB
8. Basic jQuery
9. Advanced jQuery
10. JSON + MongoDB

However, the practical PDFs available in the Library contain:
5. Java + MongoDB
6. Python + MongoDB
7. PHP + MongoDB
8/9/10. jQuery + JSON

Therefore, follow the NUMBERING USED BY YOUR TEACHER'S ACTUAL PRACTICAL FILE/JOURNAL.
The content is more important than the number.

LOCAL MONGODB NOTE
------------------
Your current Windows laptop blocks mongod.exe and mongosh.exe through its
code-integrity/security policy. These sheets therefore focus on the commands and
code you must know. When using the college VMware, use the college's mongod/mongo
workflow.

OLD COLLEGE WORKFLOW
--------------------
CMD 1:
    mongod

CMD 2:
    mongo

Modern MongoDB installations normally use mongosh instead of mongo, but the
college practical PDFs explicitly use the older mongo shell workflow.

DATABASE USED IN EXAMPLES
-------------------------
BDNS / MYDB / TYITDB-style names are interchangeable placeholders.
Change the database/collection names to whatever the question asks.

EXAM RULE
---------
Do not blindly paste every command. Execute the commands required by the exact
question and verify the output after each major operation.
