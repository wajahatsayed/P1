PRACTICAL 9 - ADVANCED jQUERY
=============================

SOURCE TOPICS
-------------
1. Callback function
2. Get/set text
3. Get/set HTML
4. Animation
5. Chaining
6. Additional advanced effects from the supplied practical file

1. CALLBACK
-----------
$("p").hide("slow", function(){
    alert("The paragraph is now hidden");
});

2. GET / SET TEXT
-----------------
var str = $("p").text();
alert(str);

$("p").text("Hello World");

3. GET / SET HTML
-----------------
var str = $("p").html();
alert(str);

$("p").html("<b>Hello World</b>");

4. ANIMATION
------------
$("#div1").animate({
    width:"150px",
    height:"150px",
    opacity:"0.5",
    left:"150px"
});

The element should have position:relative if the left property is used.

5. CHAINING
-----------
$("#p1")
  .css("color","blue")
  .slideUp(2000)
  .slideDown(2000);

FULL CALLBACK EXAMPLE
---------------------
<!DOCTYPE html>
<html>
<head>
<script src="jquery-3.3.1.min.js"></script>
<script>
$(document).ready(function(){
  $("button").click(function(){
    $("p").hide("slow", function(){
      alert("The paragraph is now hidden");
    });
  });
});
</script>
</head>
<body>
<p>Welcome to MCC</p>
<button>Click!</button>
</body>
</html>

FULL CHAINING EXAMPLE
---------------------
<!DOCTYPE html>
<html>
<head>
<script src="jquery-3.3.1.min.js"></script>
<script>
$(document).ready(function(){
  $("button").click(function(){
    $("#p1").css("color","blue").slideUp(2000).slideDown(2000);
  });

<body>

---------

college practical files.
