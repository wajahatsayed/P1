PRACTICAL 5 - JAVA WITH MONGODB
===============================

SOURCE WORKFLOW
---------------
1. Set MongoDB server path in PATH.
2. Add MongoDB Java driver JAR files.
3. Set CLASSPATH.
4. Start MongoDB shell/server.
5. Compile/run Java program from CMD.
6. Verify in MongoDB shell.

OLD PRACTICAL PATH EXAMPLE
--------------------------
C:\Program Files\MongoDB\Server\3.6\bin

JAR / CLASSPATH
---------------
The practical asks for the MongoDB Java driver JAR and a CLASSPATH entry.
Use the JAR version supplied by the college VM.

JAVA INSERT
-----------
import com.mongodb.MongoClient;
import com.mongodb.client.MongoCollection;
import com.mongodb.client.MongoDatabase;
import org.bson.Document;

public class insert {
    public static void main(String[] args) {
        MongoClient mongo = new MongoClient("localhost", 27017);
        System.out.println("Connected to the Database Successfully.");

        MongoDatabase database = mongo.getDatabase("BDNS");
        MongoCollection<Document> collection =
                database.getCollection("myCol");

        Document document = new Document();
        document.append("id", 1);
        document.append("Name", "Aarush");
        document.append("RollNo", 269729);
        document.append("Age", 20);
        document.append("College", "MCC");

        collection.insertOne(document);
        System.out.println("Document inserted successfully.");

        mongo.close();
    }
}

COMPILE / RUN PATTERN
---------------------
javac insert.java
java insert

VERIFY
------
mongo
use BDNS
show collections
db.myCol.find()

IMPORTANT
---------
The source practical uses the older MongoDB Java API. The exact JAR/API may differ
on a modern setup. For the exam, follow the Java driver JAR supplied in the
college VM.

SOURCE ALSO CONTAINS UPDATE AND RETRIEVE PROGRAMS
-------------------------------------------------
Update concept:
- connect to localhost:27017
- select database
- select myCol
- match id: 1
- update Age using $set

Retrieve concept:
- connect
- select database and myCol
- collection.find()
- iterate through returned documents
- print each document
- close connection
